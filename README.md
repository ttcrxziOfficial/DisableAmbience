# Disable Ambience
![Downloads](https://img.shields.io/badge/Downloads-128-red)
![Current Version](https://img.shields.io/badge/Version-1.0.0-blue)

# DISCLAIMER
Disable Ambience is completely CS (Client-Sided), meaning that everything this mod does, only affects Gorilla Tag locally. Disable Ambience does not modify Gorilla Tag or give the user any unfair advantage, this mod is completely meant for a better experience for recording.

Disable Ambience is currently in BETA, the mod simply only disables GameObject parents that contain weather, ambience audio, etc.

## Installation
- #### [Download BepInEx](https://github.com/BepInEx/BepInEx/tree/master) (Only compatible with BepInEx)
- #### [Download the Latest Version of Disable Ambience](https://github.com/ttcrxziOfficial/Disable-Ambience/releases)
- Drag and drop 'Disable Ambience" to your plugins folder under a path like ***"C:\Program Files (x86)\Steam\steamapps\common\Gorilla Tag\BepInEx\plugins"***
